# Contributing

Cảm ơn bạn muốn đóng góp cho DMS.

1. Fork repository, tạo branch ngắn gọn từ master.
2. Không commit API key, token, Firebase Admin credential, dữ liệu cá nhân, keystore hoặc mật khẩu.
3. Giữ header SPDX-License-Identifier: Apache-2.0 trong source mới.
4. Khi thêm dependency hoặc model, cập nhật THIRD_PARTY_NOTICES.md và DEPENDENCIES.md.
5. Chạy BUILDING.md và checklist liên quan trong TESTING.md.
6. Pull Request cần mô tả mục tiêu, cách kiểm thử, ảnh UI nếu có và tác động bảo mật/quyền riêng tư.

Bằng việc gửi đóng góp, bạn đồng ý cấp phép phần đóng góp theo Apache License 2.0 của repository.
